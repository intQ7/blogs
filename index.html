About Me

你好！我是 IntQ7，一名经验丰富的前端开发工程师，专注于构建高性能、高质量、跨平台的 Web 与小程序应用。

我熟练掌握 HTML5 / CSS3 / JavaScript (ES6+) / TypeScript，能够根据交互原型和 UI 设计图完整制作出网页，擅长解决浏览器兼容性问题与性能优化。
